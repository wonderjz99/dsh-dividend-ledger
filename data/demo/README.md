# 开箱即用的虚构数据集

这是一份**完全虚构**的数据，用于让新克隆的仓库立刻能跑通 README 里的「30 秒上手」。
公司名（虚构白酒、虚构电池…）与数字都是编的，**不对应任何真实证券**。

```bash
python3.11 -m dividend_ledger --data data/demo --text report
```

包含 6 只虚构持仓与 24 条分红事件，其中刻意覆盖了几个容易出错的边界：

| 场景 | 数据里对应什么 |
|---|---|
| 同一除权除息日有两条方案（普通 + 特殊分红） | 虚构电池 2026-04-22，两条 `proposal_sn` |
| 已公告未实施的待收 | 虚构白酒 `confirmed`、虚构银行 `proposed` |
| 缺少每股成本（成本收益率为空而非 0） | 虚构能源没有 `cost_per_share` |
| 除权日早于开始持有日（该次分红不属于本次持仓） | 多只持仓的早期事件 |
| 人工覆盖到账日 | `pay_dates.json` |

**真实数据请放在 `data/real/`**（已被 `.gitignore` 排除，不会误提交）。
