# data/ —— 虚构测试数据说明

> ⚠️ **本目录除 `events.json` 外全部是手工构造的虚构数据。**
> 证券名称一律用"虚构 XX"，代码虽然取自真实代码段（用于验证归一化与交易所后缀），
> 但**每股派息、收盘价、股数、成本全部是编造的**，不对应任何真实公司或真实账户。

## 文件

| 文件 | 角色 | 谁写 |
|---|---|---|
| `holdings.json` | **输入**：持仓 | 你维护 |
| `events.fixture.json` | **输入**：分红事件（fixture 数据源） | 你维护 / 二阶段换成 provider 抓取 |
| `events.json` | **状态**：分红事件快照 | `sync` 子命令写入 |
| `pay_dates.json` | **输入**（可选）：派息到账日人工覆盖表 | 你维护 |
| `out/ledger.json` | **输出**：计算明细账 | `report` 子命令写入 |
| `out/report.json` | **输出**：三分区汇总 | `report` 子命令写入 |

`out/` 下是**派生结果**，删掉随时可以重新生成。

## 虚构数据覆盖的边界场景

这组数据是故意设计的，每一条都对应一个测试断言：

| 股票 | 覆盖的场景 |
|---|---|
| `600519.SH` 虚构白酒 | 分红 + **送股**；有成本、有价格；多年连续分红 |
| `600377.SH` 虚构高速 | 纯现金分红；**开始持有日在两次分红之间**（早期事件应被排除） |
| `000001.SZ` 虚构银行 | 纯现金分红；含"纯配股不分配"行（应被 provider 跳过） |
| `300750.SZ` 虚构电池 | 分红 + **转增**；**开始持有日恰好在一次除权除息日之后**（边界） |
| `601988.SH` 虚构能源 | **无每股成本** → 成本收益率为 `null`；**开始持有日晚于某次分红**（整条被排除） |
| `688111.SH` 虚构科技 | **无 `close_prev`** → 股息率为 `null`；**开始持有日与一次除权除息日相隔 8 天** |
